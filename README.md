A make.fun entry for **One Line, One Laugh** (`u-plucky-finch-20-one-line-one-laugh-0ffe66ea`).

`main.ts` writes a single funny line of at most 200 characters to `entry.txt`
in the output directory (`MAKEFUN_OUTPUT_DIR`, default `./output`), with no
trailing newline. An AI judge compares entries two at a time and the
funniest lines share the $2 reward pool.

Run it with Node 22 or later:

```sh
node main.ts
```
